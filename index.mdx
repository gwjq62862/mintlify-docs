## Why SnapLogs?

<AccordionGroup>
  <Accordion title="Framework-First Design">
    Each SDK is built specifically for its framework — not a generic wrapper. Next.js SDK uses App Router patterns. NestJS SDK uses decorators, modules, and interceptors.
  </Accordion>
  <Accordion title="Structured Logging by Default">
    Every log includes: type, importance, subsystem, operation, track (user/session), metrics (latency, DB queries), security (auth status), timestamps.
  </Accordion>
  <Accordion title="Batched & Reliable">
    Automatic batching with configurable flush intervals. Graceful shutdown flushes pending logs. Retry with exponential backoff.
  </Accordion>
  <Accordion title="Query & Stream">
    Query logs with filters (type, environment, app, search, time range). Stream logs in real-time via SSE.
  </Accordion>
</AccordionGroup>
